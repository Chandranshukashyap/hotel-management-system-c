# 🏨 Hotel Management System in C

A simple **Hotel Management System** developed using the C programming language.

This project is a console-based application that allows users to select different types of hotel rooms, enter customer details, save booking information, and view previous booking history.

## 🚀 Features

- 🛏️ Different room categories
- 💰 Room pricing
- 👤 Customer information management
- 🪪 Customer ID details
- 📱 Customer mobile number storage
- 📍 Customer address storage
- 🕒 Automatic booking date and time
- 💾 File handling for storing customer records
- 📋 Booking history
- 🎨 Colored console interface using ANSI escape codes

## 🛏️ Available Room Types

| Room Type | Price |
|---|---:|
| Single Bed Room | ₹600 |
| Double Bed Room | ₹1000 |
| Single Bed Deluxe | ₹1200 |
| Double Bed Deluxe | ₹1800 |
